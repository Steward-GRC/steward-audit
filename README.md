# steward-audit 🐹

> 🧭 Tamper-evident, hash-chained audit service for Steward

## 📦 Install

```bash
go get github.com/Steward-GRC/steward-audit
```

## 🛠 Develop

```bash
task build    # go build ./...

task license  # check Apache-2.0 headers (golic)
```
